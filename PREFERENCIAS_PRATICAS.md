## 📋 Checklist de Qualidade (Seu Padrão)

Use isso para avaliar uma letra:

### **OBRIGATÓRIOS** (deve ter pelo menos 4/6):
- [ ] Metáfora visual específica (não clichê)
- [ ] Contradição ou paradoxo emocional
- [ ] Detalhes físicos/sensoriais concretos
- [ ] Linguagem coloquial autêntica
- [ ] Progressão narrativa clara
- [ ] Especificidade (não genérico)

### **DIFERENCIAIS** (quanto mais, melhor):
- [ ] Humor ou auto-ironia
- [ ] Regionalismo/cultura local
- [ ] Diálogo ou oralidade
- [ ] Sem moralismo
- [ ] Honestidade brutal
- [ ] Multilinguismo

### **PROIBIDOS** (evitar):
- [ ] ❌ Clichês românticos
- [ ] ❌ Linguagem "poética" forçada
- [ ] ❌ Emoções unidimensionais
- [ ] ❌ Moralismo/julgamento
- [ ] ❌ Abstrações vagas
- [ ] ❌ Autopiedade excessiva

## 🔥 Linha de Alta Qualidade (Seu Padrão)

Uma linha de **alta qualidade** segundo suas preferências deve ter:

1. **ESPECIFICIDADE** → Não pode ser aplicável a qualquer situação
2. **VISUALIDADE** → Cria imagem mental clara
3. **AUTENTICIDADE** → Linguagem natural do contexto
4. **COMPLEXIDADE** → Emoção não-óbvia ou contraditória

### Exemplos Perfeitos:
```
✅ "A aliança virou enfeite do dedo"
   → Específico (aliança) + Visual (enfeite) + Complexo (casamento morto)

✅ "Inveja dessa pedra"
   → Específico (pedra) + Visual (corpo deitado) + Complexo (ciúmes de objeto)

✅ "Cê me dá exposição de graça"
   → Específico (redes sociais) + Autêntico (gíria) + Complexo (meta-humor)

✅ "Flor na pedra preste a nascer"
   → Específico (planta) + Visual (flor/pedra) + Complexo (resiliência)
```
